玩法

Hoppy Blocks 沿用你熟悉的方块益智规则。把三个方块拖到 8×8 网格上，填满一整行或一整列即可消除，不断消除来累积连击。提前规划：没有方块能放下时，游戏就结束了。上手快、玩着放松，是每天动动脑的好游戏。

不只是方块游戏

除了无尽的经典模式，冒险模式还把方块益智变成 300 个关卡的旅程：收集隐藏的钻石、星星和爱心，完成分数挑战，在每个棋盘上拿到三颗星。旋转方块、请求提示，随时随地都能玩，离线也可以。

免费、离线、适合全家

Hoppy Blocks 是一款适用于 iPhone、iPad 和 Android 手机的免费益智游戏。没有账号和应用内购买，广告适合全家，无需 Wi-Fi 也能运行，非常适合通勤、坐飞机和短暂休息时玩。

常见问题

Hoppy Blocks 免费吗？

是的。Hoppy Blocks 是一款适用于 iPhone、iPad 和 Android 的免费方块益智游戏，由适合全家的广告支持。没有应用内购买。

我的进度会保存吗？

会的，保存在你的设备上。即使关闭应用，最高分、冒险模式的星星和正在玩的游戏也会保留。卸载应用会删除它们。

可以离线玩吗？

可以。所有功能无需联网都能使用，只是不会加载广告。

适合孩子玩吗？

适合。没有账号、聊天或应用内购买。广告仅限适合所有年龄、非个性化、面向儿童的内容，视频只有在玩家主动选择观看时才会播放。

如何关闭声音或振动？

使用主屏幕上的声音和振动开关。
