简要说明：Hoppy Blocks 没有账号，不会询问你的姓名、邮箱或任何其他个人信息，游戏进度保存在你的设备上。应用中唯一的外部服务是用于展示广告的 Google AdMob。每个广告请求都被标记为面向儿童，仅限适合所有年龄的内容，并且不做个性化。

关于我们

Hoppy Blocks 是一款方块益智游戏，由独立开发者 Narek Sargsyan 制作，他以 Joytap Games 的名义发布游戏（“我们”）。本政策说明你在 iOS 或 Android 上玩 Hoppy Blocks 时信息会如何处理。

我们收集的信息

我们不收集、存储或分享任何个人信息。没有注册、聊天、社交功能，也没有与他人分享任何内容的方式。

你的分数、冒险进度、正在进行的游戏以及声音、振动和语言设置只保存在你的设备上。它们不会离开设备，我们也看不到。删除应用会删除这些数据。

我们不使用任何自己的分析、崩溃报告或跟踪工具。

广告

Hoppy Blocks 免费，由 Google AdMob 广告支持。横幅广告显示在游戏棋盘之外，全屏广告只在两局之间出现，视频广告只有在玩家主动选择观看时才会出现（例如在没有空位后继续游戏）。

由于本游戏面向包括儿童在内的所有年龄段玩家，我们对 AdMob 做了如下设置：

  • 每个广告请求都被标记为面向儿童（依据美国《儿童在线隐私保护法》COPPA），并标记为来自未达同意年龄的用户（依据欧盟《通用数据保护条例》GDPR）；
  • 只展示 G 级（适合所有年龄）的广告；
  • 广告从不个性化，没有再营销或基于兴趣的广告；
  • 应用不请求广告标识符：在 iOS 上从不显示跟踪请求，也不读取 IDFA；在 Android 上没有广告 ID 权限。

为了投放广告，AdMob 仍可能处理有限的技术信息，例如你的 IP 地址（用于估算国家等大致位置）、设备和操作系统类型、应用版本，以及广告的查看和点按情况。Google 用这些信息来展示广告、限制同一广告的出现频率、衡量广告效果并防止欺诈。对于面向儿童的请求，Google 会按其政策所述限制此类处理：

  • Google 隐私权政策
  • Google 如何使用来自使用其服务的应用的信息
  • AdMob 与面向儿童的处理

儿童隐私

Hoppy Blocks 的设计目标是对儿童安全。我们不会故意收集任何人的个人信息，包括 13 岁以下儿童（或你所在国家/地区的同等最低年龄）。应用没有内购、没有广告以外的外部链接，也无法联系其他玩家。如果你是家长或监护人，并认为孩子的信息被收集了，请联系我们，我们会提供帮助。

权限

Hoppy Blocks 不会请求访问相机、麦克风、通讯录、照片或精确位置。只在加载广告时使用网络，振动只用于触感反馈，你可以在主屏幕上关闭。

你的选择

  • 你可以离线游玩。没有网络时不会加载广告，也不会发送任何内容。
  • 你可以随时卸载应用来删除所有游戏数据。
  • 根据你所在的地区，你可能有权访问或删除个人数据。由于我们不保存任何个人数据，有关广告数据的请求由 Google 通过上方链接处理，我们也很乐意协助。

政策变更

如果我们改变应用处理信息的方式，会在该变更进入应用之前更新本页面和上方的生效日期。
