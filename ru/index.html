Как играть

Hoppy Blocks сохраняет привычные правила головоломки с блоками. Перетаскивай три фигуры на поле 8×8, заполняй целый ряд или столбец, чтобы его убрать, и собирай линии подряд ради серии. Думай наперёд: когда ни одна фигура не помещается, игра окончена. Легко научиться, приятно играть — отличная ежедневная тренировка для ума.

Больше, чем игра с блоками

Кроме бесконечной Классики есть Приключение: путешествие из 300 уровней, где нужно собирать спрятанные алмазы, звёзды и сердечки, проходить испытания на очки и получать три звезды на каждом поле. Поворачивай фигуры, проси подсказки и играй где угодно, даже без интернета.

Бесплатно, без интернета, для всей семьи

Hoppy Blocks — бесплатная головоломка для iPhone, iPad и Android. Нет аккаунтов и встроенных покупок, реклама безопасна для детей, а игра работает без Wi-Fi — идеально для дороги, перелётов и коротких перерывов.

Вопросы

Hoppy Blocks бесплатная?

Да. Hoppy Blocks — бесплатная головоломка с блоками для iPhone, iPad и Android, её поддерживает безопасная для детей реклама. Встроенных покупок нет.

Сохраняется ли прогресс?

Да, на устройстве. Лучший счёт, звёзды Приключения и текущая игра сохраняются, даже если закрыть приложение. При удалении приложения они удаляются.

Можно играть без интернета?

Да. Всё работает без подключения, просто реклама не загружается.

Безопасна ли игра для детей?

Да. Нет аккаунтов, чатов и встроенных покупок. Реклама ограничена неперсонализированным детским контентом для всех возрастов, а видео запускается, только если игрок сам решит его посмотреть.

Как выключить звук или вибрацию?

Используй переключатели звука и вибрации на главном экране.
