Hoppy Blocks – 無料ブロックパズルゲーム

ドラッグ。置く。ラインを消す。

iPhone と Android 向けの癒やし系ブロックパズル。きらきらの宝石ブロックを 8×8 のマスにドラッグして縦横の列を消し、連続消しで高得点を狙おう。エンドレスのクラシックで遊ぶもよし、300 のアドベンチャーステージで隠れた宝石を探すもよし。

2つのモードと、見つける宝石

クラシック

エンドレスに遊べます。配られるピースは必ず置けるので、詰みの手札になることはありません。どこまでスコアを伸ばせる？

300 のアドベンチャーステージ

だんだん難しくなるスコアチャレンジと宝石探し。少ない手数でクリアすると星3つ。

隠れた宝石

ダイヤ、星、ハートがブロックに隠れていて、新しい宝石はピースに乗ってやってきます。その列を消して集めよう。

回転とヒント

ピースをタップすると回転、行き詰まったらヒント。少しずれて置いても自動でぴったりはまります。

おなじみのブロックパズルを、もっと楽しく

遊び方

Hoppy Blocks はおなじみのブロックパズルのルールそのまま。3つのピースを 8×8 のマスにドラッグし、横か縦の列をそろえて消し、続けて消して連続ボーナスを狙おう。先を読んで。どのピースも置けなくなったらゲームオーバー。すぐ覚えられて、のんびり遊べる、毎日の脳トレにぴったりのゲームです。

ただのブロックゲームじゃない

エンドレスのクラシックに加えて、アドベンチャーではブロックパズルが 300 ステージの旅に。隠れたダイヤ、星、ハートを集め、スコアチャレンジを突破し、どの盤面でも星3つを目指そう。ピースを回転させ、ヒントを使い、どこでも、オフラインでも遊べます。

無料・オフライン・家族向け

Hoppy Blocks は iPhone、iPad、Android スマホ向けの無料パズルゲーム。アカウントもアプリ内課金もなく、広告は家族向けで安全。Wi-Fi なしでも遊べるので、通勤や飛行機、ちょっとした休憩にぴったりです。

よくある質問

Hoppy Blocks は無料ですか？

はい。Hoppy Blocks は iPhone、iPad、Android 向けの無料ブロックパズルゲームで、家族向けの安全な広告で運営されています。アプリ内課金はありません。

進行状況は保存されますか？

はい、端末に保存されます。ベストスコア、アドベンチャーの星、プレイ中のゲームはアプリを閉じても残ります。アプリを削除すると消えます。

オフラインで遊べますか？

はい。すべて接続なしで動作します。広告が読み込まれないだけです。

子どもにも安全ですか？

はい。アカウント、チャット、アプリ内課金はありません。広告は全年齢向け・パーソナライズなし・子ども向けの内容に限られ、動画はプレイヤーが自分で見ることを選んだときだけ再生されます。

サウンドやバイブレーションをオフにするには？

ホーム画面のサウンドとバイブレーションのスイッチを使ってください。

バグを見つけた・アイデアがある

hoppyblocks.support@gmail.com までご連絡ください。お使いの端末と、iOS か Android かを書いていただけると助かります。
