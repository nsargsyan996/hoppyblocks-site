施行日：2026年11月13日

要点：Hoppy Blocks にはアカウントがなく、名前やメールアドレスなどの個人情報を求めず、ゲームの進行状況は端末に保存します。アプリが利用する外部サービスは、広告を表示する Google AdMob だけです。すべての広告リクエストは子ども向けとして指定され、全年齢向けの内容に限られ、パーソナライズされません。

運営者について

Hoppy Blocks は、Joytap Games の名前でゲームを公開している個人開発者 Narek Sargsyan（以下「私たち」）が制作したブロックパズルゲームです。このポリシーは、iOS または Android で Hoppy Blocks を遊ぶときに情報がどう扱われるかを説明します。

収集する情報

私たちは個人情報を収集、保存、共有しません。登録、チャット、ソーシャル機能はなく、ほかの人と何かを共有する手段もありません。

スコア、アドベンチャーの進行状況、プレイ中のゲーム、サウンド・バイブレーション・言語の設定は端末にのみ保存されます。端末の外に出ることはなく、私たちが見ることもできません。アプリを削除するとこれらのデータも削除されます。

独自の分析、クラッシュレポート、トラッキングのツールは使用していません。

広告

Hoppy Blocks は無料で、Google AdMob の広告で運営されています。バナー広告は盤面の外に、全画面広告はゲームの合間にのみ表示され、動画広告はプレイヤーが自分で見ることを選んだとき（例：置く場所がなくなった後に続けて遊ぶため）にのみ表示されます。

本ゲームは子どもを含むすべての年齢のプレイヤー向けのため、AdMob を次のように設定しています：

  • すべての広告リクエストを、子ども向け（米国の児童オンラインプライバシー保護法 COPPA に基づく）かつ同意年齢未満のユーザーからのもの（EU 一般データ保護規則 GDPR に基づく）として指定；
  • G 指定（全年齢向け）の広告のみを表示；
  • 広告は一切パーソナライズせず、リマーケティングや興味・関心に基づく広告もなし；
  • アプリは広告識別子を要求しません：iOS ではトラッキングの確認画面を表示せず IDFA も読み取らず、Android では広告 ID の権限を持っていません。

広告を配信するために、AdMob は限られた技術情報を処理することがあります。たとえば IP アドレス（国などのおおよその位置の推定に使用）、端末と OS の種類、アプリのバージョン、広告の表示やタップの状況などです。Google はこれを広告の表示、同じ広告の表示回数の制限、効果測定、不正防止に使います。子ども向けのリクエストについては、Google はポリシーに記載のとおりこの処理を制限します：

  • Google プライバシー ポリシー
  • Google のサービスを使用するアプリから収集した情報の Google による使用
  • AdMob と子ども向けの取り扱い

お子さまのプライバシー

Hoppy Blocks は子どもにも安全に遊べるよう作られています。13歳未満（またはお住まいの国の同等の最低年齢）の子どもを含め、誰からも意図的に個人情報を収集することはありません。アプリ内課金、広告内を除く外部リンク、ほかのプレイヤーと連絡を取る手段はありません。保護者の方で、お子さまの情報が収集されたと思われる場合はご連絡ください。対応いたします。

アクセス許可

Hoppy Blocks はカメラ、マイク、連絡先、写真、正確な位置情報へのアクセスを求めません。インターネットは広告の読み込みにのみ、バイブレーションは触覚フィードバックにのみ使用し、ホーム画面でオフにできます。

あなたの選択

  • オフラインで遊べます。接続がなければ広告は読み込まれず、何も送信されません。
  • アプリをアンインストールすれば、いつでもすべてのゲームデータを削除できます。
  • お住まいの地域によっては、個人データへのアクセスや削除の権利がある場合があります。私たちは個人データを保有していないため、広告データに関するリクエストは上記のリンクを通じて Google が対応します。お手伝いが必要な場合は喜んで協力します。

ポリシーの変更

アプリの情報の扱いを変更する場合は、その変更がアプリに反映される前に、このページと上記の施行日を更新します。
